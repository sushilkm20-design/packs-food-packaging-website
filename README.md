# PACKS Food Packaging Solutions Website

A responsive static website for PACKS Food Packaging Solutions, Varanasi, Uttar Pradesh, India.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The expected address is `https://sushilkm20-design.github.io/packs-food-packaging-website/`.
